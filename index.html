Welcome to Rituals

Rituals conducts your Rise, task-close and Shutdown. Tasks live in Super Productivity; the record lives in your Obsidian daily note. Rituals stores nothing else.

No REST API yet? Install the plugin, enable it, and copy the API key. Rituals degrades to copy/download if it's absent.

Weekly review

Bingo reads your Daily Notes/ and turns the week into a review. Rituals is about the daily spine; Bingo stays the synthesizer for now.

Bingo is a desktop app (~/repos/bingo, npm run tauri dev). Open it, pick the week, and generate. Your ritual sections now live in the same daily notes it already reads.
